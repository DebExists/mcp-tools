# TeleClaw MCP Tools — Free Search Version

This version uses free DuckDuckGo-compatible search through the `ddgs` Python package.

Tools:
- `web_search(query)`
- `read_webpage(url)`
- `read_file(file_url)`

## Deploy

1. Create a GitHub repository called `teleclaw-mcp-tools`.
2. Upload all files from this project.
3. Open Railway and create a new project.
4. Choose Deploy from GitHub Repository.
5. Select your repository.
6. Deploy.
7. Generate a public domain in Railway.
8. Copy the MCP endpoint URL into TeleClaw → Custom Connector.

No Tavily account or search API key is required.

Note: Railway itself may have account/payment requirements depending on its current plan. The search tool itself does not require a paid API key.
